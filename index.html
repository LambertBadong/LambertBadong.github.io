FoxFab Engineering Vault

An Obsidian second brain for a switchgear design team, run with Claude Code.

foxfab-engineering-vault↗
The idea · a second brain

Team know-how lives in heads, spreadsheets and CAD folders. The vault makes every job, part and workday a linked note — “which jobs used this part?” is one click.

How the vault works
1
Structure
PARA folders: jobs, engineering reference, one note per part, daily notes, templates.
2
Job intake
“New job …” — Claude Code reads the release form, fills the job note, links the reference job.
3
Job finish
“I finished …” — Claude reads the BOM, links every part, diffs it against the reference job.
4
Live CAD monitor
A Python watcher logs every new SolidWorks file to the day’s note, every 10 s.
5
Audit & sync
Every AI task is logged to dashboards; the vault syncs via PowerShell and Git.
